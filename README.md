# PocketLeagueSideSwipeVita
A port of Pocket League Side Swipe PSP to the PS Vita


This is the first release of Rocket League Portable, a Rocket League SideSwipe style game for the PSP/PS VITA. The game physics are a little different, but you will quickly get used to it.

It is AI assisted as there was not much information on the internet about coding a PSP/PS Vita game in Lua. However, after learning some of the basics, I did code a lot of it myself.

The game was compiled with VitaSDK.

This game is still a work in progress. I know there are a couple of bugs, but I am very open to feedback, so please let me know what you think.


## Controls:
Left/Right: D-pad, Tilt Up/Down: L/R, Jump/Flip: X, Boost: O Pause: Start Main Menu: Select

## Installation:
Download the VPK file and move it to the data folder of a modded PS Vita. Then install the VPK through VitaShell.
